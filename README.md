# Vértice: downloads dos apps

Este repositório guarda **somente** os arquivos de instalação (APK) dos apps e o manifesto de versões. Não há código-fonte aqui.

- `versoes.json`: versão mais recente de cada app, com link, SHA-256, tamanho e novidades. É lido pela página de downloads e pelo aviso de atualização dentro dos apps.
- **Releases**: um por versão de cada app (ex.: `vertice-crm-v1.0.11`).

Os apps exigem login com uma conta autorizada. Baixar o APK não dá acesso a nenhum dado.

## Instalar no Android
1. Baixe o APK mais recente em **Releases**.
2. Abra o arquivo. Se o Android pedir, permita "instalar apps desconhecidos" para o navegador ou o gerenciador de arquivos.
3. Para atualizar, instale a versão nova por cima. Não desinstale a anterior.
